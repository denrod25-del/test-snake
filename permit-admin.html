Permit data refresh (admin)

Developer and operator notes for refreshing cached permit JSON. Not linked from public Permit Search — use public search for research.

How to refresh permit data

The public page reads data/permits/sources.json at boot, then loads each entry's dataFile in parallel. After a scrape, hard-refresh the public page (Ctrl+Shift+R).

Scraper commands

cd scraper
pip install -r requirements.txt
python scrape_permits.py -v
python scrape_permits.py --only "West Palm Beach" -v

Default lookback is 90 days (configurable in parsers_permits.py). Output paths match dataFile in the manifest.

File paths

  • data/permits/sources.json — frontend manifest
  • scraper/sources_permits.json — scraper jurisdiction config
  • data/permits/west-palm-beach.json, boca-raton.json, etc. — cached permit files
  • scraper/parsers_permits.py — Tyler / Click2Gov / SagesGov parsers

Status legend

  • active — scraper works; file is real cached municipal data
  • sample / unsupported_paywall — demo or blocked portal; do not label as live on public pages
  • scaffold — parser stub; sample data until reverse-engineered

Adding a new city portal

  1. Add parser in scraper/parsers_permits.py and register in PERMIT_PARSERS.
  2. Add entry to scraper/sources_permits.json.
  3. Add matching entry to data/permits/sources.json.
  4. Run scraper; verify JSON shape with scraper/tests/test_permit_output_shape.py.
