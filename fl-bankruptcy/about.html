About this project

How the tracker works

This is a front-end for federal bankruptcy filings in Florida. It ships with a synthetic dataset so the UI is functional out-of-the-box — wire it to a real source whenever you're ready.

Important: the bundled data in data/filings.json is illustrative only — names, case numbers, and amounts are randomly generated. Nothing on this page should be treated as a real court record.

The three Florida bankruptcy districts

Bankruptcy in the U.S. is filed in federal court. Florida is split across three districts, each with multiple divisional offices:

Northern District (N.D. Fla.)

Tallahassee, Pensacola, Panama City, Gainesville. Covers the Panhandle and north-central counties.

Middle District (M.D. Fla.)

Tampa, Orlando, Jacksonville, Fort Myers, Ocala. The largest district by caseload.

Southern District (S.D. Fla.)

Miami, Fort Lauderdale, West Palm Beach. Covers the southeast plus the Keys.

Replacing the demo data with real filings

The front-end only depends on the shape of data/filings.json. Any pipeline that writes that file (or an API endpoint with the same JSON) will work. Sensible options:

  • CourtListener / RECAP — a free archive of PACER documents maintained by the Free Law Project. Has an open REST API and is the cheapest practical source.
  • PACER — the official federal court records system. Authoritative but charges $0.10/page (capped at $3/document). Each district has its own bankruptcy court endpoint (FLNB, FLMB, FLSB).
  • Court RSS feeds — each Florida bankruptcy court publishes a free, last-24-hours RSS feed of new filings (limited fields).
  • Commercial aggregators — e.g. Epiq, Stretto, BankruptcyData. Faster onboarding, paid.

A typical pipeline runs nightly: fetch new filings → normalize into the schema below → overwrite data/filings.json.

Schema

Each entry in the filings array looks like:

{
  "id":              "flbk-00001",
  "case_number":     "26-04001",
  "filed_date":      "2026-04-12",
  "chapter":         "7",
  "chapter_label":   "Chapter 7 — Liquidation",
  "district_code":   "FLMB",
  "district_name":   "Middle District of Florida",
  "district_short":  "M.D. Fla.",
  "division":        "Tampa",

Legal notes

  • U.S. bankruptcy filings are public records by statute (11 U.S.C. § 107).
  • Personally identifying information (full SSNs, full account numbers, minors' names, etc.) must be redacted under Fed. R. Bankr. P. 9037 before publication.
  • Republishing PACER content is permitted; many fields are also free via court RSS.

Running locally

The site is a static folder — no build step. Browsers block fetch() on file://, so serve it with any static server:

cd fl-bankruptcy
python -m http.server 8000
# then open http://localhost:8000

Regenerate the demo data with:

python scripts/generate_mock_data.py
