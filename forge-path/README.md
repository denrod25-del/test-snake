# Forge Path

Separate from `swe-academy`: a **Next.js** course shell with typed curriculum (**14 modules · 27 lessons**), quizzes, fill-in-the-blank and reorder drills, XP/streak, and Library links (no copyrighted book text).

Curriculum lives in `src/curriculum/modules/` (`frontend`, `react-next`, `backend`, `data`, `advanced`, `capstone`, plus craft/web/js).

## Run locally

```bash
cd forge-path
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router), React, TypeScript, Tailwind v4
- Zustand + `localStorage` for progress (export/import JSON in Settings)
