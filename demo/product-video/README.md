# DeedScout product video

Build a 1080p walkthrough MP4 from branded HTML slides plus live Netlify screenshots.

```bash
cd demo/product-video
python3 build_video.py
```

Output lands in `/opt/cursor/artifacts/deedscout-video/out/DeedScout-Product-Walkthrough.mp4`.

Requires: Google Chrome (headless), ffmpeg, Pillow.
