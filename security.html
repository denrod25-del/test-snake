Security & responsible disclosure

DeedScout uses Supabase Auth, Stripe for billing, and Netlify Functions for server-side Pro checks. User-owned data (watchlists, alerts, profiles) is protected by Row Level Security policies in Supabase.

Report a vulnerability: Use our contact form with topic "Security" or email through the contact page. Please include steps to reproduce and impact assessment. Do not publicly disclose before we acknowledge.

Account data: Request export or deletion via contact form or account settings. See Privacy Policy for retention.

Forms: Netlify honeypot on public forms. Rate limiting on API endpoints is planned for production hardening.
